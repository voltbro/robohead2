# Документация: ROS2 нода `ears_driver`

## Общее описание

Нода `ears_driver` управляет двумя сервоприводами («ушами» робоголовы) через ШИМ-контроллер **PCA9685**, подключённый по шине **I2C** (`/dev/i2c-1`). Движение к целевому углу выполняется по **кубическому полиному** (плавный разгон и торможение) с частотой обновления **50 Гц**. Если `duration = 0`, перемещение мгновенное (максимально допустимая скорость сервоприводов).

---

## Сервисы

### 1. `<namespace>/ears_set_angle`

| Поле | Значение |
|------|----------|
| **Тип** | `robohead_interfaces/srv/Move` |
| **Имя по умолчанию** | `ears_set_angle` (настраивается параметром `srv_ears_set_angle_name` в конфиг-файле) |

#### Запрос

| Поле | Тип | Описание |
|------|-----|----------|
| `angle_a` | `int16` | Целевой угол **левого** уха (градусы). В диапазоне `[l_from, l_to]` (настраивается в конфиг-файле) |
| `angle_b` | `int16` | Целевой угол **правого** уха (градусы). В диапазоне `[r_from, r_to]` (настраивается в конфиг-файле) |
| `duration` | `float64` | Время движения к цели (секунды). `0.0` — мгновенное перемещение |


Положительное (>0) значение целевого угла двигает ухо **вперед**, отрицательное (<0) - **назад**

#### Ответ

| Поле | Тип | Описание |
|------|-----|----------|
| `data` | `int16` | Код результата |

#### Коды ответа

| Код | Значение |
|-----|----------|
| `0` | Успех |
| `-1` | `angle_a` (левое ухо) вне допустимого диапазона `[l_from, l_to]` |
| `-2` | `angle_b` (правое ухо) вне допустимого диапазона `[r_from, r_to]` |
| `-3` | `duration` отрицательный |

#### Допустимые значения (по умолчанию из конфига)

| Параметр | Диапазон |
|----------|----------|
| `angle_a` | от **-90** до **90** |
| `angle_b` | от **-90** до **90** |
| `duration` | **≥ 0.0** |

### 2. `<namespace>/is_idle`

| Поле | Значение |
|------|----------|
| **Тип** | `robohead_interfaces/srv/SimpleCommand` |
| **Имя по умолчанию** | `is_idle` (настраивается параметром `srv_is_idle_name`) |

#### Запрос

Пустой (используется только для вызова).

#### Ответ

| Поле | Тип | Описание |
|------|-----|----------|
| `data` | `bool` | `true` — сервоприводы достигли целевого угла; `false` — движение ещё продолжается |

## Параметры конфигурации

Файл: `config/years_driver.yaml`

### Имена сервисов

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| `srv_ears_set_angle_name` | `string` | `"ears_set_angle"` | Имя сервиса задания углов |
| `srv_is_idle_name` | `string` | `"is_idle"` | Имя сервиса проверки состояния |

### Начальное положение

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| `std_left_angle` | `int` | `0` | Начальный угол левого уха при запуске |
| `std_right_angle` | `int` | `0` | Начальный угол правого уха при запуске |

### I2C и PCA9685

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| `i2c_address` | `int` | `64` (0x40) | I2C-адрес PCA9685 |
| `servo_1_channel` | `int` | `7` | Канал PCA9685 для **левого** уха |
| `servo_2_channel` | `int` | `6` | Канал PCA9685 для **правого** уха |
| `servo_1_coef` | `int` | `0` | Поправка угла для сервопривода 1 (механическая калибровка) |
| `servo_2_coef` | `int` | `0` | Поправка угла для сервопривода 2 (механическая калибровка) |
| `servo_pulse_low` | `int` | `130` | Минимальное значение PWM (соответствует 0°) |
| `servo_pulse_high` | `int` | `530` | Максимальное значение PWM (соответствует 180°) |

### Ограничения углов

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| `constraints.l_from` | `int` | `-90` | Минимальный допустимый угол левого уха |
| `constraints.l_to` | `int` | `90` | Максимальный допустимый угол левого уха |
| `constraints.r_from` | `int` | `-90` | Минимальный допустимый угол правого уха |
| `constraints.r_to` | `int` | `90` | Максимальный допустимый угол правого уха |

## Логика преобразования углов

Пользовательский угол (например, `angle_a = 20`) преобразуется в угол сервопривода:

```
servo_1_angle = 90 + left  + servo_1_coef   (левое ухо)
servo_2_angle = 90 - right - servo_2_coef   (правое ухо, инвертировано)
```

Результат ограничивается диапазоном `[0, 180]` и переводится в PWM-импульс линейной интерполяцией между `servo_pulse_low` и `servo_pulse_high`.

---

## Планирование траектории

При `duration > 0` используется **кубический полином** с нулевыми начальной и конечной скоростями:

```
θ(t) = a0 + a2·t² + a3·t³
```

где:
- `a0 = θ_current`
- `a2 = 3·(θ_goal − θ_current) / T²`
- `a3 = −2·(θ_goal − θ_current) / T³`

Движение прекращается, когда евклидово расстояние до цели < 0.5° или прошло время `duration`.

При `duration = 0` — сервоприводы движутся к целевому углу с максимально возможной скоростью.

## Примеры взаимодействия



## Сборка

```bash
colcon build --symlink-install --packages-select robohead_interfaces ears_driver
```

## Запуск

```bash
ros2 launch ears_driver ears_driver.launch.py 
```

Вывод при успешном запуске:
```
[INFO] [launch]: Default logging verbosity is set to INFO
[INFO] [ears_driver_node-1]: process started with pid [12312]
[ears_driver_node-1] [INFO] [1773672078.279887145] [ears_driver.ears_driver]: INITED
```

### Из командной строки

```bash
# Плавное движение обоих ушей в позицию (45 левое, -70 правое) за 1.5 секунды
ros2 service call /ears_driver/ears_set_angle robohead_interfaces/srv/Move \
  "{angle_a: 45, angle_b: -70, duration: 1.5}"

# Мгновенное перемещение в стартовую позицию
ros2 service call /ears_driver/ears_set_angle robohead_interfaces/srv/Move \
  "{angle_a: 0, angle_b: 0, duration: 0.0}"

# Проверка, завершено ли движение
ros2 service call /ears_driver/is_idle robohead_interfaces/srv/SimpleCommand
# Попробуйте сделать duration порядка 10 секунд и повызывать этот сервис
```

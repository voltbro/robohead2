

# Документация: ROS2 нода `neck_driver`

## Общее описание

Нода `neck_driver` управляет двумя сервоприводами шеи робоголовы (наклон и поворот) через ШИМ-контроллер **PCA9685**, подключённый по шине **I2C** (`/dev/i2c-1`). Два сервопривода работают совместно: их комбинация обеспечивает вертикальное (наклон вверх/вниз) и горизонтальное (поворот влево/вправо) перемещение головы. Движение к целевому углу выполняется по **кубическому полиному** (плавный разгон и торможение) с частотой обновления **50 Гц**. Если `duration = 0`, перемещение мгновенное (с максимально допустимой скоростью сервоприводов).

## Сервисы

### 1. `<namespace>/neck_set_angle`

| Поле | Значение |
|------|----------|
| **Тип** | `robohead_interfaces/srv/Move` |
| **Имя по умолчанию** | `neck_set_angle` (настраивается параметром `srv_neck_set_angle_name`) |

#### Запрос

| Поле | Тип | Описание |
|------|-----|----------|
| `angle_a` | `int16` | Целевой **вертикальный** угол (наклон головы, градусы) из диапозона `[v_from, v_to]` |
| `angle_b` | `int16` | Целевой **горизонтальный** угол (поворот головы, градусы) из диапозона `[h_from, h_to]`  |
| `duration` | `float64` | Время движения к цели (секунды). `0.0` — мгновенное перемещение |

**Вертикальный** угол: положительное значение - движение вверх, отрицательное значение - движение вниз
**Горизонтальный** угол: положительное значение - движение вправо, отрицательное значение - движение влево

#### Ответ

| Поле | Тип | Описание |
|------|-----|----------|
| `data` | `int16` | Код результата |

#### Коды ответа

| Код | Значение |
|-----|----------|
| `0` | Успех |
| `-1` | `angle_a` (вертикальный угол) вне допустимого диапазона `[v_from, v_to]` |
| `-2` | `angle_b` (горизонтальный угол) вне допустимого диапазона `[h_from, h_to]` |

|----------|----------|

| `angle_b` (horizontal) | от **-30** до **30** |
| `duration` | **≥ 0.0** |

## Параметры конфигурации

Файл: `config/neck_driver.yaml`

### Имена сервисов

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| `srv_neck_set_angle_name` | `string` | `"neck_set_angle"` | Имя сервиса задания углов шеи |
| `srv_is_idle_name` | `string` | `"is_idle"` | Имя сервиса проверки состояния |

### Начальное положение

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| `std_vertical_angle` | `int` | `0` | Начальный вертикальный угол при запуске |
| `std_horizontal_angle` | `int` | `0` | Начальный горизонтальный угол при запуске |

### I2C и PCA9685

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| `i2c_address` | `int` | `64` (0x40) | I2C-адрес PCA9685 |
| `servo_1_channel` | `int` | `5` | Канал PCA9685 для **правого** сервопривода шеи |
| `servo_2_channel` | `int` | `4` | Канал PCA9685 для **левого** сервопривода шеи |
| `servo_1_coef` | `int` | `0` | Поправка угла для сервопривода 1 (механическая калибровка) |
| `servo_2_coef` | `int` | `0` | Поправка угла для сервопривода 2 (механическая калибровка) |
| `servo_pulse_low` | `int` | `120` | Минимальное значение PWM (соответствует 0°) |
| `servo_pulse_high` | `int` | `550` | Максимальное значение PWM (соответствует 180°) |

### Ограничения углов

| Параметр | Тип | По умолчанию | Описание |
|----------|-----|-------------|----------|
| `constraints.v_from` | `int` | `-30` | Минимальный допустимый вертикальный угол |
| `constraints.v_to` | `int` | `30` | Максимальный допустимый вертикальный угол |
| `constraints.h_from` | `int` | `-30` | Минимальный допустимый горизонтальный угол |
| `constraints.h_to` | `int` | `30` | Максимальный допустимый горизонтальный угол |

> Не рекомендуется изменять ограничения углов. При чрезмерно больших занчениях поворота сервоприводов есть риск механического повреждения конструкции робоголовы.

## Логика преобразования углов

Два сервопривода работают **дифференциально**: их комбинация обеспечивает независимое управление наклоном (vertical) и поворотом (horizontal).

Пользовательские углы `vertical` и `horizontal` преобразуются в углы сервоприводов:

```
servo_1_angle = 90 - vertical - horizontal + servo_1_coef   (правый серво)
servo_2_angle = 90 + vertical - horizontal + servo_2_coef   (левый серво)
```

| Движение | servo_1 | servo_2 | Описание |
|----------|---------|---------|----------|
| Наклон вверх (`vertical > 0`) | уменьшается | увеличивается | Сервоприводы вращаются в противоположных направлениях |
| Наклон вниз (`vertical < 0`) | увеличивается | уменьшается | Сервоприводы вращаются в противоположных направлениях |
| Поворот вправо (`horizontal > 0`) | уменьшается | уменьшается | Сервоприводы вращаются в одном направлении |
| Поворот влево (`horizontal < 0`) | увеличивается | увеличивается | Сервоприводы вращаются в одном направлении |

Результат ограничивается диапазоном `[0, 180]` и переводится в PWM-импульс линейной интерполяцией между `servo_pulse_low` и `servo_pulse_high`.

## Планирование траектории

При `duration > 0` используется **кубический полином** с нулевыми начальной и конечной скоростями:

```
θ(t) = a0 + a2·t² + a3·t³
```

где:
- `a0 = θ_current`
- `a2 = 3·(θ_goal − θ_current) / T²`
- `a3 = −2·(θ_goal − θ_current) / T³`

Движение прекращается, когда евклидово расстояние до цели < 0.5° или прошло время `duration`.

При `duration = 0` — мгновенная установка угла (с максимально возможной скоростью сервоприводов).

## Примеры взаимодействия

## Сборка

```bash
colcon build --symlink-install --packages-select robohead_interfaces neck_driver
```

## Запуск

```bash
ros2 launch neck_driver neck_driver.launch.py 
```
Вывод при успешном запуске:
```
[INFO] [launch]: Default logging verbosity is set to INFO
[INFO] [neck_driver_node-1]: process started with pid [13509]
[neck_driver_node-1] [INFO] [1773673357.916763891] [neck_driver.neck_driver]: INITED
```

### Из командной строки

```bash
# Плавный наклон вверх на 20° и поворот вправо на 15° за 1.5 секунды
ros2 service call /neck_driver/neck_set_angle robohead_interfaces/srv/Move \
  "{angle_a: 20, angle_b: 15, duration: 1.5}"

# Мгновенное возвращение в нейтральную позицию
ros2 service call /neck_driver/neck_set_angle robohead_interfaces/srv/Move \
  "{angle_a: 0, angle_b: 0, duration: 0.0}"

# Проверка, завершено ли движение
ros2 service call /neck_driver/is_idle robohead_interfaces/srv/SimpleCommand
```
